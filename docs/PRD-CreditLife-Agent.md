# CreditLife-Agent 一页纸 PRD

> 版本 v1.0（2026-09-27）｜作者：薛梓琏｜项目：信贷全生命周期多 Agent 智能客服系统
> 配套文档：[评测报告](评测报告.md)｜[竞品分析](竞品分析-AI客服.md)｜[仓库](https://github.com/ZLX0071/CreditLife-Agent)

## 1. 背景与问题

银行信用卡与消费信贷客服有两个结构性痛点：**规则密集**（息费、分期、征信规则因卡种/产品而异，人工培训成本高）与**合规高压**（推荐理财、征信表述、催收行为都有明确监管红线，GB/T 45251-2025 与中银协 2026 指引将催收合规推到监管风暴眼）。通用客服机器人在这两个场景的失效模式一致：意图分流不准、事实口径编造、危机与对抗场景无护栏。

## 2. 目标与指标体系

**北极星**：单轮解决数（无需人工介入即闭环的会话数）。
**输入指标**：意图识别准确率（组级 ≥85%）、合规红线命中率（=0）、转人工率（监控但不压抑——该转就转）、端到端延迟（≤10s）。
**护栏指标**：合规对抗用例正确处理率 100%（任何一轮回归跌破即回滚）。

## 3. 用户与核心场景

| 用户 | 场景 | 风险等级 |
|------|------|---------|
| 信用卡持卡人 | 账单/还款规则、分期、年费积分、争议交易与盗刷、办卡进度 | 中（息费口径错误=投诉） |
| 贷后用户 | 还款失败、逾期费用、协商还款、征信异议、催收投诉 | **高**（违规话术=监管事件） |
| 极端情形 | 轻生威胁、冒名借款、诱导违规 | **极高**（确定性处理） |

## 4. 方案概述

多 Agent 编排（账单/技术/综合/人工四类角色，规则打分路由+主辅协作）+ 双业务线 Skill 话术规范（关键词精确分流）+ 意图驱动 RAG（改写→并行召回→重排→Top-K）+ 三层记忆 + **合规评测闭环**（LLM-as-Judge 五维含合规维度、94 条分层评测集、双 Judge 校准、人工抽标）+ 危机干预确定性拦截。

## 5. 需求优先级

- **P0**：意图三路融合识别、RAG 检索与工具治理、合规红线护栏（Skill 层）、危机干预前置拦截、评测回归基线
- **P1**：双业务线 Skill 切分、监控降权、缓存失效一致性、双 Judge 校准、分层评测集
- **P2**：Skills 语义匹配兜底、完整对话记录持久化、管理端鉴权与限流、检索质量独立评测集

## 6. 关键决策记录（ADR）

| 决策 | 备选方案 | 选择理由 |
|------|---------|---------|
| Judge 增加 compliance 维度 | 仅四维质量分 | 金融场景"答得对"不等于"答得合规"；红线必须可量化、可回归 |
| 危机干预用确定性代码 | 交给 LLM 判断 | 安全关键路径不依赖概率；实测路由层前置拦截 100% 触发 |
| RAG 用"Agent 自主调用+强制工具策略" | 意图门控预检索 | 门控依赖意图准确率，误判即漏检；实测门控方案存在漏触发，工具策略方案修复后触发正常 |
| 双业务线用 Skill 关键词切分 | 新增两个独立 Agent | 复用编排/记忆/评测全链路；代价是关键词对口语化脆弱（已知，Roadmap 有语义兜底方案） |
| Judge 同模型 + 三层校准 | 直接换更强 Judge | 成本；用双 Judge 对比 + 人工抽标（容差一致率 96%）量化偏差并披露 |

## 7. 上线后实验规划

1. 工具策略强弱 AB：强制策略 vs 温和建议，观测 RAG 触发率与 Judge 准确性变化
2. 危机拦截对照：前置拦截 vs 意图路由，对比触发率（预期 100% vs <100%）
3. 合规回归节奏：每次 Prompt/Skill 变更必跑 12 条对抗用例，红线命中即阻断发布

## 8. 当前数据（详见评测报告）

94 条分层评测集：合规 1.00、通过率 96.6%、意图组级 77.8%（卡线 93.3%）、双 Judge 一致率 100%（合规维）、人工抽标容差一致率 96%。

## 9. 边界与风险

不替代人工审批（减免/提额/征信更正一律转人工）；息费口径以合同与公示为准；管理端当前无鉴权（演示部署，生产前必须补）；业务语料为演示用通用口径。
