# 信用卡分期业务规则说明（演示知识库）

## 分期类型

- 账单分期：对已出账单的全部或部分消费金额申请分期。
- 单笔消费分期：对单笔达到起分金额的消费申请分期。
- 现金分期：将额度内资金转入本人同名借记卡，按分期偿还（预借现金类业务，通常不享受免息待遇）。

## 费用规则

- 分期手续费按期数不同而不同，常见可选期数为 3、6、12、18、24 期，以办理页面实时展示的费率为准。
- 手续费收取方式分为每期收取与一次性收取两种，以产品说明为准；宣传中的"月费率"折算为年化利率后通常高于名义月费率，请以页面展示的近似年化利率为准。
- 提前结清：剩余期数手续费是否收取、如何收取，以领卡合同与产品条款为准，办理页面通常有试算工具。

## 注意事项

- 分期占用信用额度，已分期部分额度通常随每期还款逐步恢复。
- 分期申请是否通过以系统评估为准；账单分期通常有申请金额门槛与申请时限（一般为账单日后至到期还款日前若干天）。
- 分期不影响最低还款额计算中的已出账部分；申请成功的分期金额计入下期账单起按期摊还，具体以账单展示为准。
