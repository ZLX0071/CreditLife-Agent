# 安全用卡与防诈指南（演示知识库）

## 用卡安全习惯

- 卡片背面 CVV 码可遮贴；不在不明网站/链接输入卡号、有效期、CVV、验证码。
- 收到"异常消费""积分到期"类短信，一律通过官方 APP 或卡片背面热线核实，不点短信链接。
- 开启交易通知与限额管理（官方 APP 安全中心）。

## 常见诈骗特征

- 冒充客服来电要求"屏幕共享""取消会员否则扣费""配合资金核查"——官方客服绝不会要求转账或屏幕共享。
- "注销校园贷/征信修复"类话术均属诈骗；征信不能付费修复。
- 引导下载非官方渠道 APP、开启无障碍权限的，立即终止。

## 疑似盗刷处理

1. 官方 APP 一键锁卡或挂失（优先操作）。
2. 核对账单确认非本人交易，发起争议交易流程（见争议交易处理文档）。
3. 保留短信与消费通知作为证据。
4. 必要时报警。
